# Speak Up · Practica inglés hablado con IA

Web para practicar conversación en inglés hablando con una IA (Claude) como si tuvieras a una persona delante.

- Niveles A1 → C2
- Temas de conversación (o el tuyo propio), la IA no deja que la conversación se pare
- Correcciones amables en español
- Subtítulos en inglés (y traducción opcional al español)
- Modo manos libres, repetir, repetir despacio y botón "¿Qué digo?"

**Requisitos:** Google Chrome o Microsoft Edge (reconocimiento de voz) y una API key de Anthropic (se guarda solo en tu navegador).
